# 审核提示词 · prompt_ver = reviewer-v2

你是英汉学习者词典的审校。另一位编纂者已按 `prompts/writer.md` 的规范写好词条。
先完整阅读 `{WRITER_PROMPT}`（规范全文），然后逐条审核 `{WRITER_OUTPUT}`。

参考资料（可选）：`{OLD_REF}` 是旧版人工整理的释义（CSV，列：单词,词频排名,来源层,原释义,清理后释义）。
**只用它检查「是否漏掉了常用义项」或「排序明显不对」，严禁照抄其措辞。** 只看「清理后释义」列，忽略「原释义」列。
旧版里没有的词就只凭你自己的知识审。不要上网。

## 审什么（按重要性）
1. **skip 判断**是否正确（该收的被跳、该跳的被收）。
2. **义项错误**：释义不对、把冷僻义当常用义、遗漏了一个普通学习者必须知道的常用义项。
3. **排序**：第一个义项是否是现代最常用的意思。
4. **词性**错误。
5. 音标：`ipa_uk` 全部审；`ipa_us` 审重音位置、双主重音、单音节带重音符等明显错误（CMU 数据也会出错）。`syllables`、`word_family` 里的不存在词或不同词源的词、`affixes` 的牵强拆分、`level`、`offensive/kid_safe`。
6. `register` 里的领域必须在写手规范的领域表内。

措辞偏好不同、近义词选择不同、义项数目差一条但都正确，**不算问题**，不要改。
`syllables` 的切分点只要读得通（各词典惯例本就不同，如 ad·apt·a·ble / a·dapt·a·ble），**不算问题**；只有拼写不符、明显切错音节数时才改。

## 输出

写到 `{OUTPUT}`：JSONL，与写手输出一一对应、顺序一致，每行：

- 没问题：`{"id":"w001097","word":"happy","verdict":"ok"}`
- 有问题：
```json
{"id":"…","word":"…","verdict":"fix",
 "issues":["义项排序：第一义应为…","遗漏常用义 n. …"],
 "fixed":{ …按写手格式给出完整的修订版词条（含 skip 判断）… }}
```

`issues` 用中文简短写明每个问题。`fixed` 必须是完整词条，不能只给改动字段。
写完后回复一行：`done <ok数> <fix数>`。
