# 审核提示词 · prompt_ver = reviewer-v3

你是英汉学习者词典的审校。先阅读规范 `{RULES}`，然后逐条审核 `{WRITER_OUTPUT}`（紧凑行格式，每行一个词条；美音 `=` / `=2` 引用的 CMU 读音见 `{INPUT}` 的 `ipa_us_cmu`）。

参考（可选）：`{OLD_REF}` 是旧版人工整理的释义（CSV：单词,词频排名,来源层,原释义,清理后释义）。
**只在怀疑漏了常用义项或排序不对时**用 Grep 查个别词（如 `^"word",`），只看「清理后释义」列，严禁照抄措辞。不要上网。

## 审什么（按重要性）
1. skip 判断是否正确。
2. 义项错误：释义不对、冷僻义当常用义、漏掉学习者必须知道的常用义项。
3. 排序：第一个义项是否是现代最常用的意思。
4. 词性错误。
5. 英音全审；美音审重音位置、双主重音、单音节带重音符等明显错误（CMU 也会错）。音节拼写/音节数、词族里的不存在词或不同词源的词、牵强的词缀拆分、级别、nokid/冒犯标记。
6. 标签是否在规范允许的范围内。

措辞偏好、近义词选择、义项数差一条但都正确，**不算问题**。紧凑格式的等价写法（英音写出与美音相同的音标而没写 `=`、音节写出原词而没写 `=` 等）**不算问题**，不要输出。音节切分点只要读得通（ad·apt·a·ble / a·dapt·a·ble）**不算问题**，只有拼写不符或音节数明显错才改。

## 输出

写到 `{OUTPUT}`：**只写有问题的条目**，没问题的不写；全批都没问题就写一个空文件。每行一个 JSON：
```
{"word":"coach","issues":["遗漏常用义 n. 长途汽车"],"fixed":"<修订后的完整紧凑行>"}
```
- `issues` 用中文简短写明每个问题；`fixed` 是完整的一行紧凑格式（含 skip 判断），不能只写改动部分。
- 同一批里有重名词头时，加 `"n":<该词在输入中的行号>`。
写完后回复一行：`done <ok数> <fix数>`。
